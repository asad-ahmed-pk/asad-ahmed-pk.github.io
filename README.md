# Asad Ahmed: online CV & robotics freelancing

Personal site: <https://asad-ahmed-pk.github.io>. Online CV (`/`) and freelance robotics services (`/services`).

Hosted on **GitHub Pages**: every push to `main` deploys `site/` via GitHub Actions (`.github/workflows/pages.yml`).

## Stack

Static HTML, no framework, no Node/npm (same stack as the Glitch Leopard Studios site).

| Piece | What | Version |
|---|---|---|
| CSS | [Tailwind CSS](https://tailwindcss.com) v4 **standalone CLI** (`brew install tailwindcss`). `src/input.css` builds into `site/assets/css/site.css`, which is **committed**, so CI runs no build. | 4.3.5 |
| JS | `site/assets/js/site.js`: print button + active nav link. Progressive enhancement only. | n/a |
| Icons | [Lucide](https://lucide.dev) SVGs, inlined; sources in `src/icons/lucide-1.66.0/` (ISC). `github.svg` is Lucide's legacy brand icon. | 1.66.0 |
| Hero art | `site/assets/img/scan.svg`, a lidar point cloud generated by `tool/make_scan.py` | n/a |
| Fonts | system fonts only | n/a |
| Tooling | `tool/*.sh`, `tool/check.py`, `tool/serve.py` (Python stdlib) | n/a |

## Local development

```sh
brew install tailwindcss   # once
tool/dev.sh                # Tailwind --watch + http://localhost:8126
```

Before committing:

```sh
tool/build.sh              # minified site/assets/css/site.css
python3 tool/check.py      # links, assets, alt text, one h1, header/footer, no inline styles, CSS fresh
```

## Deploy (one-time setup)

1. GitHub repo → **Settings → Pages → Build and deployment → Source: GitHub Actions**.
2. Push to `main`. The workflow runs `tool/check.py` (without the CSS check) and publishes `site/`.

## Repository map

```
site/                 everything GitHub Pages publishes
  index.html          the CV
  services.html       freelance services (/services)
  404.html            not-found page (GitHub Pages serves it automatically)
  assets/css/site.css built by Tailwind, do not edit
  assets/js/site.js   print button, nav highlight
  assets/img/scan.svg generated hero point cloud
  favicon.svg, robots.txt, sitemap.xml
src/input.css         Tailwind entry: @theme tokens, components, print stylesheet
tool/                 build.sh · dev.sh · serve.py · check.py · make_scan.py
.github/workflows/    pages.yml (deploy)
```

The CV content comes from `~/Developer/job_hunt_workspace/src/resume/robotics.tex`. "Print / PDF" on the page uses a print stylesheet, so a browser "Save as PDF" gives a clean A4 CV.
